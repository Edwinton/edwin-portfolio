OmniShare — Secure Share Portal

Problem
Three common sharing tasks (QR codes, shortened URLs, secure file/text sharing) each require separate tools, most of which want an account. Built one app that does all three without registration.
My role
Built end-to-end: Flask backend with QR generation (qrcode + Pillow), URL shortener with click tracking and 96-hour expiry, secure share with password protection and automatic cleanup, plus an HTMX + Tailwind frontend. Deployed with Gunicorn.
Learned
How to structure a multi-feature Flask app, manage in-memory vs. on-disk state, run background cleanup with threading, use HTMX for partial-page updates, and ship a Python web app to production.
  • Flask
  • Python
  • HTMX
  • Tailwind
  • Pillow
  • Gunicorn

Full-stack

LeaveMail — Smart Leave Assistant

Problem
Parents often struggle to write formal leave emails — mobile typing is slow, formatting is unclear, and email clients are complex. Existing tools assume desktop use and English fluency.
My role
Built a mobile-first Flask app with four email templates, six visual themes, Web Speech API voice input, quick presets, and a full accessibility layer (high contrast, large text, reduced motion). Includes settings, local history, and PIN/password/pattern lock with server-side hashing.
Learned
How to design for accessibility-first use, handle session-cookie limits safely, hash credentials before storage, escape user input to prevent XSS in previews, and ship a Flask app on Render.
  • Flask
  • Python
  • JavaScript
  • Web Speech API
  • Render
